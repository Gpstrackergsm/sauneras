# Sauneras Shopify Brand Theme 🧖‍♀️🔥
**Official Shopify OS 2.0 Theme for [sauneras.com](https://sauneras.com)**

A modern, high-converting direct-to-consumer (DTC) Shopify theme engineered for **Sauneras** — specialists in Portable Steam & Infrared Saunas for home and indoor use.

---

## 🌟 Key Features & Sections

- **Sauneras Custom Design System**:
  - Calming Scandinavian / Japanese spa color palette (Pine Green `#1F362B`, Warm Amber/Terracotta `#CF6E3C`, Warm Linen Canvas `#FAF7F2`).
  - Native Vector Logos (`assets/sauneras-logo.svg` & `assets/sauneras-logo-white.svg`).
  - Custom UI stylesheet (`assets/sauneras-custom.css`).

- **High-Converting Storefront Sections**:
  - `sauneras-hero`: High-impact hero section with dynamic trust badges, heat specs pills (140°F, 5-min rapid steam), and dual CTAs.
  - `sauneras-benefits`: Interactive benefit cards highlighting cellular detox, joint/muscle recovery, sleep improvement, calorie burning, and 60-second pop-up convenience.
  - `sauneras-comparison`: Interactive comparison table (*Sauneras Portable Spa* vs. *$6,000+ Traditional Wood Cabin Saunas*).
  - `sauneras-how-it-works`: 3-step visual guide (Unfold & Pop Up ➔ Fill & Heat ➔ Sweat & Rejuvenate).
  - `sauneras-testimonials`: Social proof cards with star ratings, verified buyer badges, and satisfaction metrics (98% sleep improvement, 94% pain relief).
  - `sauneras-guarantee`: Risk-Free 30-Day In-Home Trial guarantee banner.
  - `sauneras-faq`: Expandable accordion addressing buyer inquiries (temperatures, electricity usage, cleaning, aromatherapy).

- **Performance & Shopify OS 2.0**:
  - Slide-out Cart Drawer (`cart_type: "drawer"`) for instant checkout.
  - Predictive search with product pricing and ratings.
  - Fast asset delivery, zero external script bloat.

## 🚀 Quick Start / Local Development

### 1. Preview with Shopify CLI
```bash
shopify theme dev --store <your-store-subdomain>.myshopify.com
```

### 2. Push directly to your Shopify Store
```bash
shopify theme push --store <your-store-subdomain>.myshopify.com
```

### 3. Check theme syntax & best practices
```bash
shopify theme check
```
